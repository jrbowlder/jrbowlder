# Hi, I'm Jimmy

I'm a firefighter in Idaho, and I'm learning to build software on [Boot.dev](https://www.boot.dev). I work in Python, mostly on the data side: pulling messy records out of systems that were never designed to share them, cleaning them up, and putting something useful on top.

Outside of shift I run trails, ski, and work on a 1994 Land Rover Discovery. I run Arch Linux every day, and I would rather self-host a service than pay a subscription for it.

## What I'm working on

- **[sunvalleyfiredata](https://github.com/jrbowlder/sunvalleyfiredata)**: a warehouse and dashboard for my fire department. Three source systems, a Python ETL, a SQLite warehouse, a Streamlit dashboard, and Tableau-ready extracts. It joins incident records to the staffing calendar, which no vendor report does.
- **[web-crawler](https://github.com/jrbowlder/web-crawler)**: an async site crawler that visits every page on a site and writes a JSON report.
- **[toy_agent_bootdev](https://github.com/jrbowlder/toy_agent_bootdev)**: a small AI agent that can list files, read them, run Python, and write code back.
